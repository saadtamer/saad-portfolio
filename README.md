## 🌟 Overview
Welcome to my official interactive portfolio! This web application showcases my journey, projects, research presentations, and certifications in **Artificial Intelligence, Machine Learning, Deep Learning, Generative AI (LLMs & RAG), and Computer Vision**.

Built with modern high-performance web technologies, featuring a responsive, interactive, dark cyber-glassmorphism aesthetic.

- **Core AI & Data Science:** Python, PyTorch, TensorFlow, Scikit-Learn, OpenCV, LangChain, LlamaIndex, Pinecone, HuggingFace
- **Deployment:** Vite, Vercel / Netlify ready

## 🛠️ Quick Start & Local Setup

```bash
# 1. Clone the repository
git clone https://github.com/saadtamer/saad-portfolio.git

# 2. Navigate to the project directory
cd saad-portfolio

# 3. Install dependencies
npm install

# 4. Start the local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.
